# DBN Digit Generation

This project generates synthetic handwritten digit images using a Deep Belief Network (DBN) and Restricted Boltzmann Machines (RBMs).

## Technologies
- Python
- PyTorch
- Streamlit
- NumPy
- Matplotlib
- MNIST Dataset

## How to Run

Install dependencies:

python -m pip install -r requirements.txt

Start the application:

python -m streamlit run app.py
